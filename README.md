# Josh Symonds

Engineer building agent platforms, evaluation systems, and AI infrastructure.<br>
Santa Barbara, CA · [joshsymonds.com](https://joshsymonds.com) · [LinkedIn](https://www.linkedin.com/in/joshsymonds/) · [Email](mailto:josh@joshsymonds.com)

I've spent fifteen years in infrastructure and security, from building M1 Finance's platform as employee #8 to running industrial edge fleets and multi-cluster Kubernetes. Since 2025 I build by directing coding agents. Most of my time goes to the specs, gates, and evals that decide what the agents ship, and to the platforms they run on.

## Now

**Director of SRE, Consumer Product** at Attain

- **Agent platform.** Built Marvin, Attain's company-wide agent platform in Slack, used across engineering, support, and operations. Agents run as ephemeral Kubernetes workers with per-user OAuth, Cedar policies on every tool, and versioned model routes with one-step rollback.
- **Evaluation.** Built a harness that replays production code reviews against candidate models, and used it to move review to open-weight models.
- **Incidents.** Automated first-pass investigation of production alerts, including merge requests that fix the alerted bug.
